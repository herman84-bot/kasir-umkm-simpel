# Aturan Utama Proyek Kasir UMKM Simpel

Aturan ini akan selalu dibaca oleh agen Antigravity setiap kali bekerja di *workspace* ini.

1. **Gunakan TypeScript:** 
   - Anda HARUS SELALU memprioritaskan penulisan menggunakan **TypeScript** (`.ts` / `.tsx`) untuk semua pembuatan *script* atau komponen baru.
   - Jika melakukan perubahan besar pada file JavaScript (`.js`) yang sudah ada, pertimbangkan untuk bermigrasi secara bertahap ke TypeScript, serta pastikan memiliki definisi tipe data (type-safety) yang jelas.

2. **Kerapian Kode (Clean Code):**
   - Hasilkan kode yang sangat rapi, bersih, dan mematuhi standar *clean code*. 
   - Jangan tinggalkan *dead code* (kode tak terpakai) atau fungsi *log* sembarangan. 
   - Beri penjelasan pada fungsi yang rumit.

3. **Pola Kerja ala Claude Code (Proaktif & Ringkas):**
   - **Proaktif Bertindak:** Jangan terlalu banyak bertanya atau meminta izin (kecuali untuk hal krusial). Langsung gunakan alat (*tools*) untuk mencari file, membaca kode, menjalankan *script*, dan mengedit file guna menyelesaikan tugas.
   - **Sangat Ringkas (Concise):** Hilangkan basa-basi. Jawab dengan sangat singkat, padat, dan *to-the-point*.
   - **Kemandirian (Autonomous Debugging):** Jika perintah terminal gagal atau ada *error* kompilasi, selidiki log-nya, perbaiki masalahnya secara mandiri, dan coba jalankan ulang. Jangan langsung berhenti dan melaporkannya ke pengguna, kecuali Anda sudah kehabisan akal.
   - **Eksplorasi Konteks:** Sebelum mengubah kode, pastikan selalu membaca file yang terkait terlebih dahulu untuk memastikan perubahannya aman (sejalan dengan prinsip pada GEMINI.md).
