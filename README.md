# Kasir UMKM Simpel

Aplikasi kasir dan manajemen stok berbasis HTML, Tailwind CSS, dan Vanilla JavaScript.

## Cara pakai
1. Buka file `index.html` di browser.
2. Gunakan menu di samping untuk membuka Dashboard, Kasir, Inventory, dan Riwayat.
3. Data otomatis tersimpan di browser dengan `localStorage`.

## Fitur
- Dashboard statistik dan grafik penjualan.
- Kasir satu layar dengan keranjang, diskon, pajak, dan struk cetak.
- Inventory dengan CRUD dan indikator stok kritis.
- Riwayat transaksi dengan pencarian.
- Export data CSV.
- Dark mode dan multi-kasir.
